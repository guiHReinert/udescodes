# Somando Inteiros

Faça um programa capaz de somar números muito grandes (maiores que 64bits).

Utilize o método de sua escolha. Porém, não podem ser utilizadas nenhuma biblioteca ou linguagem que trate esse propósito.

Você pode escolher se utilizará notação decimal ou binária. Considere que o usuário poderá inserir os parâmetros e o programa deverá apresentar o valor.

    Em decimal é mais didático, cada dígito numa posição de uma string (existem outros métodos)
    Em binário é mais eficiente, cada posição do vetor contem uma parte de 32/64 bits do número.

O algoritmo deve somar corretamente: 9.223.372.036.854.775.807 + 1

## Compilação

```c
clear && gcc main.c -o main && ./main
```
